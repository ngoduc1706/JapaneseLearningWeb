# Giới thiệu dự án
Dự án JapaneseLearningWeb là ứng dụng web dành cho việc học tiếng Nhật, giúp người dùng nâng cao kỹ năng ngôn ngữ một cách dễ dàng và hiệu quả.

# Tính năng chính
- Hệ thống bài học phong phú
- Kiểm tra từ vựng và ngữ pháp
- Hỗ trợ học qua video và hình ảnh

# Công nghệ sử dụng
- Spring Boot
- Thymeleaf
- Java
- PostgreSQL

# Hướng dẫn thiết lập và chạy
1. Clone repository: `git clone https://github.com/ngoduc1706/JapaneseLearningWeb.git`
2. Di chuyển vào thư mục dự án: `cd JapaneseLearningWeb`
3. Chạy ứng dụng: `mvn spring-boot:run`

# Lưu ý về kiểm thử
Dự án bao gồm các bài kiểm thử tự động để đảm bảo chất lượng mã nguồn. Bạn có thể chạy kiểm thử bằng lệnh `mvn test`.
